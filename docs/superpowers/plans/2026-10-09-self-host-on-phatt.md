# Self-host blog.no42.org on phatt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve blog.no42.org from phatt.labmonkeys.space behind Traefik and Anubis, built by GitHub Actions as a GHCR image, and retire Netlify.

**Architecture:** A multi-stage Dockerfile builds the Hugo site and packs it into an unprivileged nginx image. GitHub Actions runs a smoke test on every PR and pushes the image to GHCR on `main`. The `werkzeughalle` Ansible collection deploys the compose project, the Anubis allow rule and an update timer on phatt. DNS at INWX moves last, after a full comparison against Netlify.

**Tech Stack:** Hugo 0.167.0 (official image), nginx 1.30 (nginx-unprivileged, alpine), Docker Buildx, GitHub Actions, GHCR, Traefik v3 labels, Anubis v1.27.0 policy, Ansible, systemd timers, bash, curl.

**Spec:** `docs/superpowers/specs/2026-10-09-self-host-on-phatt-design.md`

### Deviations from the spec, found while planning

- **No `--minify`.** Netlify's build does not minify. Minifying would make every page body differ and break the comparison in Task 8.
- **CSP header added.** `static/_headers` makes Netlify send `Content-Security-Policy: frame-ancestors 'none';` on every page. nginx ignores that file, so the Traefik headers middleware sets it instead.
- **Sitemap is an index.** Hugo's `/sitemap.xml` lists `/en/sitemap.xml` and `/de/sitemap.xml`. Netlify serves a flat sitemap generated by a plugin instead. The comparison script reads Netlify's sitemap and handles both forms.
- **Provenance via Buildx.** `make publish` attaches the SBOM and SLSA provenance with `docker buildx build --sbom=true --provenance=mode=max`. No separate attestation action, so the workflow only needs `packages: write`.
- **New managed project directory.** The `anubis` role never creates `/etc/docker/<project>`. Task 5 adds that, together with enabling the unit.
- **Healthcheck on 127.0.0.1.** busybox wget in the image resolves `localhost` to `::1`, and nginx only listens on IPv4. The healthcheck uses `http://127.0.0.1:8080/`.

## Review Focus

- **A directory URL without a trailing slash** (`/article/opennms-oci`) must answer `301` with the relative `Location: /article/opennms-oci/`, like Netlify. nginx's default absolute redirect would leak `:8080`. Pinned in Task 1 smoke test.
- **A feed URL with a query string** (`/index.xml?utm_source=x`) from a `Mozilla` user agent must pass Anubis. forwardAuth includes the query in the path. Pinned in Task 4 policy test.
- **Feed paths on other hosts** (`pdf.no42.org/index.xml`) must still get the challenge. The allow rule must be host-scoped. Pinned in Task 4 policy test.
- **The first timer run on a fresh host** has no local image yet. It must pull and start the project, not crash on the empty image ID. Pinned in Task 6 update test.
- **A failed pull** must leave the running container alone and exit non-zero, so the journal shows it. Pinned in Task 6 update test.

```bash
#!/usr/bin/env bash
# Copyright 2026 Ronny Trommer <ronny@no42.org>
# SPDX-License-Identifier: CC-BY-NC-SA-4.0
#
# Checks a running blog image over HTTP.
# Usage: smoke.sh [base-url]   (default http://localhost:8080)
set -uo pipefail
BASE=${1:-http://localhost:8080}
fail=0

check() { # path want-code [header-regex] [body-regex]
  local path=$1 want=$2 hre=${3:-} bre=${4:-} hdr body code ok=1
  hdr=$(mktemp)
  body=$(mktemp)
  code=$(curl -s -m 10 -D "$hdr" -o "$body" -w '%{http_code}' "$BASE$path")
  [[ $code == "$want" ]] || ok=0
  [[ -z $hre ]] || tr -d '\r' <"$hdr" | grep -qiE "$hre" || ok=0
  [[ -z $bre ]] || grep -qE "$bre" "$body" || ok=0
  if ((ok)); then
    echo "ok   $path -> $code"
  else
    echo "FAIL $path: got $code, want $want${hre:+ header /$hre/}${bre:+ body /$bre/}"
    fail=1
  fi
  rm -f "$hdr" "$body"
}

check / 200 '^cache-control: public, max-age=300$' '<meta name="author" content="Ronny Trommer">'
check /article/opennms-oci/ 200 '' 'class="admonition'
check /article/opennms-oci 301 '^location: /article/opennms-oci/$'
check /index.xml 200 '^content-type: (text|application)/(rss\+)?xml'
check /tags/opennms/index.xml 200 '^content-type: (text|application)/(rss\+)?xml'
check /sitemap.xml 200 '' '<sitemapindex'
check /does-not-exist/ 404 '' '404 Page not found'

css=$(curl -s -m 10 "$BASE/" | grep -oE 'theme\.min\.[0-9a-f]{64}\.css' | head -1)
if [[ -n $css ]]; then
  check "/$css" 200 '^cache-control: public, max-age=31536000, immutable$'
else
  echo "FAIL /: no fingerprinted theme CSS linked"
  fail=1
fi

exit $fail
```

```nginx
# Copyright 2026 Ronny Trommer <ronny@no42.org>
# SPDX-License-Identifier: CC-BY-NC-SA-4.0
#
# Static blog behind Traefik. Traefik handles TLS and compression.
server {
    listen 8080;
    server_name _;
    root /usr/share/nginx/html;
    index index.html;
    server_tokens off;

    # Traefik terminates TLS on 443. Absolute redirects would point at
    # http://<host>:8080, so send relative Location headers like Netlify.
    absolute_redirect off;

    location / {
        try_files $uri $uri/ =404;
        add_header Cache-Control "public, max-age=300" always;
    }

    # Hugo Pipes fingerprints (64 hex) and processed images (_hu_<hash>) never change.
    location ~ (\.[0-9a-f]{64}\.(css|js)|_hu_[0-9a-f]{16,}\.[a-z]+)$ {
        add_header Cache-Control "public, max-age=31536000, immutable";
    }

    error_page 404 /404.html;
    location = /404.html {
        internal;
        add_header Cache-Control "public, max-age=300" always;
    }
}
```

### Task 3: Site comparison script

**Files:**
- Create: `scripts/compare-sites.sh`

**Interfaces:**
- Consumes: nothing.
- Produces: `scripts/compare-sites.sh [candidate-ip]`.
  - Reference: `$REF`, default `https://blog-no42-org.netlify.app`.
  - Candidate: `https://blog.no42.org`. With `candidate-ip` (IPv4 or IPv6), requests go to that address with `--resolve` and `-k`.
  - Prints `DIFF <path>: ...` per mismatch and `<n> URLs compared, <d> differ`. Exit 0 when nothing differs.
  - When both sides send the same redirect, it follows that one hop and compares the target. A `DIFF` on the target names the original path and the target.
  - Used in Task 8 and Task 9.

- [ ] **Step 1: Write the script**

Create `scripts/compare-sites.sh` and make it executable:

```bash
#!/usr/bin/env bash
# Copyright 2026 Ronny Trommer <ronny@no42.org>
# SPDX-License-Identifier: CC-BY-NC-SA-4.0
#
# Compares every sitemap URL between a reference and a candidate.
# Usage: compare-sites.sh [candidate-ip]
#   REF       reference base URL (default https://blog-no42-org.netlify.app)
#   candidate https://blog.no42.org, sent to candidate-ip with --resolve and -k when given
# Paths come from $REF/sitemap.xml. A sitemap index is expanded one level, and a flat
# urlset is used as is. Six fixed paths are added.
# A failed sitemap fetch, or a sitemap with no URLs, exits 1.
# Per path, status codes must match. A 3xx compares the redirect target path, with
# scheme and host stripped. Any other response compares the body bytes.
# A request that fails (status 000) on either side is a DIFF.
# When both sides redirect with the same status to the same target path, that target
# is fetched once more on both sides and compared the same way. At most one hop is
# followed. The path counts once, and a DIFF names the original path and the target.
# The Netlify-injected comment is removed from the reference body before comparing.
# Uses curl's default user agent, which Anubis does not challenge.
set -uo pipefail
REF=${REF:-https://blog-no42-org.netlify.app}
HOST=blog.no42.org
IP=${1:-}

cand_opts=()
if [[ -n $IP ]]; then
  addr=$IP
  [[ $IP == *:* ]] && addr="[$IP]"
  cand_opts=(--resolve "$HOST:443:$addr" -k)
fi

locs() { grep -oE '<loc>[^<]+</loc>' | sed -E "s#</?loc>##g; s#^https://$HOST##"; }
strip() { sed -E 's#^https?://[^/]+##' <<<"$1"; }
fetch() {
  curl -fsS -m 20 "$1" || { echo "error: cannot fetch $1" >&2; return 1; }
}

tmp=$(mktemp -d)
trap 'rm -rf "$tmp"' EXIT

sitemap=$(fetch "$REF/sitemap.xml") || exit 1
: >"$tmp/raw"
if grep -q '<sitemapindex' <<<"$sitemap"; then
  for sm in $(locs <<<"$sitemap"); do
    body=$(fetch "$REF$sm") || exit 1
    locs <<<"$body" >>"$tmp/raw"
  done
else
  locs <<<"$sitemap" >>"$tmp/raw"
fi
if [[ ! -s $tmp/raw ]]; then
  echo "error: no URLs found in $REF/sitemap.xml" >&2
  exit 1
fi

{
  cat "$tmp/raw"
  printf '%s\n' / /index.xml /index.json /sitemap.xml /robots.txt /does-not-exist/
} | sort -u >"$tmp/paths"

# Fetches one path from both sides and sets ca, ra, cb, rb and why.
# why is empty when both sides match.
compare() {
  local a b
  : >"$tmp/a"
  : >"$tmp/b"
  a=$(curl -s -m 20 -o "$tmp/a" -w '%{http_code} %{redirect_url}' "$REF$1")
  b=$(curl -s -m 20 -o "$tmp/b" -w '%{http_code} %{redirect_url}' ${cand_opts[@]+"${cand_opts[@]}"} "https://$HOST$1")
  ca=${a%% *}; ra=${a#* }
  cb=${b%% *}; rb=${b#* }
  perl -0pi -e 's/<!-- This site is hosted on Netlify\..*?-->\n?//s' "$tmp/a"

  why=
  if [[ $ca == 000 || $cb == 000 ]]; then
    why=curl
  elif [[ $ca != "$cb" ]]; then
    why=status
  elif [[ $ca == 3* ]]; then
    [[ $(strip "$ra") == "$(strip "$rb")" ]] || why=redirect
  else
    cmp -s "$tmp/a" "$tmp/b" || why=body
  fi
}

n=0
d=0
while read -r p; do
  [[ -n $p ]] || continue
  n=$((n + 1))
  compare "$p"
  via=
  if [[ -z $why && $ca == 3* ]]; then
    target=$(strip "$ra")
    if [[ -n $target ]]; then
      compare "$target"
      via=" (redirect target $target)"
    fi
  fi

  if [[ -n $why ]]; then
    da=; db=
    [[ $ca == 000 ]] && da="curl failed"
    [[ $cb == 000 ]] && db="curl failed"
    [[ $ca == 3* ]] && da="-> $(strip "$ra")"
    [[ $cb == 3* ]] && db="-> $(strip "$rb")"
    [[ $why == body ]] && da=body && db=body
    echo "DIFF $p$via: reference $ca $da, candidate $cb $db"
    d=$((d + 1))
  fi
done <"$tmp/paths"

echo "$n URLs compared, $d differ"
[[ $d -eq 0 ]]
```

```bash
# Copyright 2026 Ronny Trommer <ronny@no42.org>
# SPDX-License-Identifier: MIT
#
# Runs blog-update against stub docker and systemctl commands.
# Usage: test-update.sh
set -uo pipefail
cd "$(dirname "$0")" || exit 1
SCRIPT=$PWD/../files/blog-update
T=$(mktemp -d)
trap 'rm -rf "$T"' EXIT
mkdir -p "$T/bin" "$T/project"
fail=0

# docker image inspect answers $ID_1 on the first call, $ID_2 on the second.
# An empty value means the image does not exist locally.
cat >"$T/bin/docker" <<'EOF'
#!/usr/bin/env bash
echo "docker $*" >>"$STUB_LOG"
case "$1 $2" in
  "image inspect")
    n=$(grep -c '^docker image inspect' "$STUB_LOG")
    var="ID_$n"
    [[ -n ${!var:-} ]] || exit 1
    echo "${!var}" ;;
  "compose pull")
    [[ ${PULL_FAILS:-0} == 1 ]] && exit 1
    exit 0 ;;
  "image prune")
    [[ ${PRUNE_FAILS:-0} == 1 ]] && exit 1
    exit 0 ;;
esac
EOF
cat >"$T/bin/systemctl" <<'EOF'
#!/usr/bin/env bash
echo "systemctl $*" >>"$STUB_LOG"
EOF
chmod +x "$T/bin/docker" "$T/bin/systemctl"

PRUNE='docker image prune -f --filter label=org.opencontainers.image.source=https://github.com/indigo423/blog.no42.org'

# name id1 id2 pull-fails prune-fails want-exit want-restart(yes|no) want-prune(yes|no)
case_() {
  : >"$T/log"
  STUB_LOG=$T/log ID_1=$2 ID_2=$3 PULL_FAILS=$4 PRUNE_FAILS=$5 PATH="$T/bin:$PATH" \
    "$SCRIPT" "$T/project" img:latest docker-compose@blog.service >/dev/null 2>&1
  local rc=$? restarted=no pruned=no
  grep -q '^systemctl restart docker-compose@blog.service$' "$T/log" && restarted=yes
  # The prune only counts when it follows the restart.
  sed -n '/^systemctl restart /,$p' "$T/log" | grep -qxF "$PRUNE" && pruned=yes
  if [[ $rc == "$6" && $restarted == "$7" && $pruned == "$8" ]]; then
    echo "ok   $1"
  else
    echo "FAIL $1: exit $rc restart $restarted prune $pruned, want exit $6 restart $7 prune $8"
    fail=1
  fi
}

case_ "new image restarts the project and prunes" sha256:a sha256:b 0 0 0 yes yes
case_ "same image leaves the project alone" sha256:a sha256:a 0 0 0 no no
case_ "first run without a local image restarts and prunes" "" sha256:b 0 0 0 yes yes
case_ "failed pull exits non-zero and keeps the container" sha256:a sha256:a 1 0 1 no no
case_ "failed prune still exits zero after the restart" sha256:a sha256:b 0 1 0 yes yes

exit $fail
```

```bash
#!/usr/bin/env bash
# Copyright 2026 Ronny Trommer <ronny@no42.org>
# SPDX-License-Identifier: MIT
#
# Pulls the images of a compose project and restarts its unit when <image> changed.
# After a restart it prunes dangling images of the blog repo. A failed prune is
# logged and does not fail the run.
# Usage: blog-update <project-dir> <image> <unit>
# A rollback pins compose.yml to a sha- tag. <image> stays :latest and is no
# longer pulled, so its ID does not change and the unit is not restarted.
set -euo pipefail
dir=${1:?project directory}
image=${2:?image}
unit=${3:?unit}

before=$(docker image inspect --format '{{.Id}}' "$image" 2>/dev/null || true)
cd "$dir"
docker compose pull --quiet
after=$(docker image inspect --format '{{.Id}}' "$image")

if [[ $before != "$after" ]]; then
  echo "new image $after (was ${before:-none}), restarting $unit"
  systemctl restart "$unit"
  docker image prune -f --filter label=org.opencontainers.image.source=https://github.com/indigo423/blog.no42.org ||
    echo "pruning old blog images failed, continuing"
else
  echo "image unchanged ($after)"
fi
```
